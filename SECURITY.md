# Security Policy

## Supported Versions

This is the official website for SSS Little Stars Primary School.
We currently maintain and support the latest version of this website.

| Version | Supported |
| ------- | --------- |
| Latest  | ✅        |

## Reporting a Vulnerability

If you find a security issue on our school website, please report it responsibly.

**Do NOT post vulnerabilities publicly.**

To report a security issue, please email:
📧 [ssslittlestarsedu@gmail.com]

Please include:
- Description of the vulnerability
- Steps to reproduce it
- Potential impact

We will respond within 7 days and take appropriate action.

Thank you for helping keep our school website safe!
